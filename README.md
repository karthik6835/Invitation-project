# 💌 InviteLuxe - AI-Powered Digital Invitation Management System

**InviteLuxe** is a modern, full-stack web application designed to create, manage, and share stunning digital invitations for weddings, parties, corporate events, and special occasions. Built with cutting-edge web technologies, it provides a seamless and interactive experience for both event hosts and guests.

---

## 🚀 Key Features

* **🎨 Custom Template Gallery:** Choose from a wide variety of professionally designed invitation templates tailored for different events.
* **⚡ Interactive Editor:** Easily customize event details, themes, fonts, and colors in real-time.
* **👥 Guest List Management:** Effortlessly track RSVPs, manage guest responses, and monitor attendance status.
* **☁️ Cloud Database Integration:** Securely store and manage all invitation and guest data using **Supabase**.
* **📱 Fully Responsive Design:** Optimized for seamless viewing across desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Tailwind CSS
* **Backend & Database:** Supabase (PostgreSQL, Authentication, Real-time APIs)
* **Version Control:** Git & GitHub
